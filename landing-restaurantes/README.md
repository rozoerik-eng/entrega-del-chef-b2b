# LP 01 — Restaurantes y Cocinas Industriales

## Objetivo

Capturar leads de dueños de restaurantes, chefs ejecutivos y encargados de compras
que buscan un proveedor confiable de insumos para su operación diaria.

## Independencia de despliegue

Esta carpeta es autosuficiente. Para desplegarla en Cloudflare Pages:
1. Conectar solo esta carpeta como raíz del proyecto
2. No requiere archivos de `landing-catering/` ni `landing-hoteles-casinos/`

## Estructura interna

```
landing-restaurantes/
├── index.html          # Página principal (pendiente de desarrollo)
├── assets/             # CSS, JS propios de esta landing
├── images/             # Imágenes específicas de restaurantes
└── components/         # Fragmentos HTML reutilizables internamente
```
