# LP 03 — Hoteles y Casinos

## Objetivo

Capturar leads de gerentes de alimentos y bebidas (F&B), jefes de compras
y directores de operaciones en hoteles, resorts y casinos.

## Independencia de despliegue

Esta carpeta es autosuficiente. Para desplegarla en Cloudflare Pages:
1. Conectar solo esta carpeta como raíz del proyecto
2. No requiere archivos de las otras landings

## Estructura interna

```
landing-hoteles-casinos/
├── index.html          # Página principal (pendiente de desarrollo)
├── assets/             # CSS, JS propios de esta landing
├── images/             # Imágenes específicas de hoteles/casinos
└── components/         # Fragmentos HTML reutilizables internamente
```
